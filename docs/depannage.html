Dépannage

Les messages que tu vois vraiment, et ce qu'ils veulent dire.

Test impossible: lancement refusé

Le test s'est arrêté avant le graphe. Causes restantes: tu n'es pas en vie, la technique n'est pas enregistrée (sauvegarde le brouillon), ou l'endurance bloque un lancement qui n'est pas un test.

Un test ne doit plus échouer parce qu'il manque un ballon, une cible ou une position. Recharge le gamemode après la mise à jour serveur, puis reteste.

Rien n'est cliquable dans Skill rapide

La liste de type s'ouvrait derrière la fenêtre. Rouvre le studio pour prendre la nouvelle version de l'éditeur. La fenêtre est maintenant indépendante, et la liste s'ouvre dedans.

attempt to index global 'RBP'

Ancien éditeur. Ferme et rouvre le studio. Le bouton Créer utilise RivalsBP.

Je ne vois pas Studio, ni Tester

  1. dev 1 dans la console.
  2. Ton SteamID est propriétaire.
  3. Rouvre le menu des techniques.

Le graphe a l'air bon, le test dit qu'il y a des erreurs

Onglet Problèmes, ou vue Code: la ligne soulignée. Tant qu'une erreur reste, le test ne part pas.

Les joueurs ne voient pas ma technique

Il faut Publier, puis visibilité Public. L'onglet Studio du menu des techniques montre d'abord les brouillons aux personnes autorisées.

Deux personnes sur la même technique

Une seule peut écrire. L'autre est en lecture seule, avec le pseudo affiché à droite. Le verrou tombe au bout de 45 secondes sans signe de vie.

Généré depuis le module Rivals BP. Relance sync.ps1 après un changement.
