Ouvrir le studio

Deux portes. Les deux vérifient la même chose: mode développeur, et SteamID propriétaire.

Conditions

  1. Ton SteamID64 est dans la liste des propriétaires de Gestion.
  2. En jeu, ouvre la console et tape dev 1.
Sans dev 1, le studio, l'onglet Studio du menu des techniques, et les boutons TESTER restent cachés. Le serveur refuse aussi la demande.

Depuis Gestion

Console: gestion. Onglet Rivals BP. L'éditeur s'ouvre en plein écran.

Depuis les techniques

Touche B. Choisis une technique. Bouton ÉDITEUR. L'onglet Studio liste les techniques créées dans l'éditeur.

Ce qui n'existe plus

Il n'y a plus de commande joueur bl_rbp. En console serveur seulement: rbp_status et rbp_reload.

Après une mise à jour du code

  • Fichiers serveur (lancement, blocs, accès): recharge le gamemode.
  • Fichiers de l'éditeur: ferme le studio et rouvre-le. Le client reçoit un nouveau paquet.
Généré depuis le module Rivals BP. Relance sync.ps1 après un changement.
