Créer une technique

Le plus court chemin: une notification. Si elle s'affiche, le studio, le graphe et le test fonctionnent.

Skill rapide

  1. En haut, Rapide.
  2. Type: Notification.
  3. Nom: alerte_test (lettres, chiffres, underscore, commence par une lettre).
  4. Créer le skill.

Le studio pose deux blocs déjà reliés: quand le sort part, puis afficher un texte. Le joueur du second bloc est le lanceur.

Tester

Sauvegarde, puis Tester ou F5. Tu dois voir le texte en jeu. Pas de ballon, pas de cible, pas de coût.

Un test ignore les anciennes conditions de la technique Lua (ballon, position, cible), le gel, le tir en cours et l'étourdissement. Un vrai lancement, hors test, les respecte encore.

Rendre la technique jouable

  1. Valider (Ctrl+Entrée). Corrige ce qui est listé dans Problèmes.
  2. Publier. L'ancienne version est archivée, empreinte SHA-256.
  3. Visibilité: Test (toi et les autres développeurs propriétaires) ou Public (tout le monde).

Tant que ce n'est pas publié en Public, les joueurs normaux ne l'ont pas. Le brouillon n'est jamais joué.

Autres départs

  • Gauche, onglet PRESETS: dash, tir, passe, notification, et d'autres chaînes déjà reliées.
  • Bouton Skill: technique vide, ou à partir d'un modèle.
  • Vue Code: tu peux aussi l'écrire. Voir le langage.
skill "alerte_test" {
    on cast {
        notify("Technique lancée")
    }
}

Fiche

Nom affiché, description, rang, style, icône, recharge, endurance. Ces champs suivent le même style que le reste du studio: fond sombre, bord clair, focus cyan.
