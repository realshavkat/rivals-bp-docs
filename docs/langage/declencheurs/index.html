Déclencheurs du langage

Dans la vue Code, on cast réveille un bloc événement. Chaque nom est expliqué dans Exemples.

ball_lost​

Bloc: Event.OnBallLost.

on ball_lost {
    notify("déclenché")
}

ball_possess​

Bloc: Event.OnBallPossess.

on ball_possess {
    notify("déclenché")
}

cancel​

Bloc: Event.OnCancel.

on cancel {
    notify("déclenché")
}

cast​

Bloc: Event.OnSkillCast.

on cast {
    notify("déclenché")
}

event​

Bloc: Event.Custom.

on event("signal") {
    notify("déclenché")
}

Bloc: Event.OnFlowDeactivate.

    notify("déclenché")
