Langage d'étapes

Une deuxième écriture du graphe. Fichier .rbs. Le nom dans le projet est langage d'étapes. L'extension ne s'allonge pas.

Le serveur découpe le texte en jetons, puis en graphe. Il n'y a pas de CompileString. Un mot inconnu est une erreur, pas un appel.

Squelette

skill "tir_court" {
    name = "Tir court"
    style = "isagi"
    rank = "B"
    cooldown = 6
    stamina = 15

    on cast {
        windup(0.35)
        shoot(8000, lift = 80)
        notify("Frappé")
    }
}

Règles utiles

  • L'identifiant: lettres, chiffres, _, commence par une lettre.
  • Un commentaire -- au-dessus d'une étape est gardé sur le bloc.
  • requires sert au vrai lancement. Un test depuis le studio ne bloque pas dessus.
  • Une valeur après une attente se range avec set, puis se relit avec get.
  • La durée max couvre toute la technique, attentes comprises.

Modèles fournis

Dash, tir, passe, dribble, buff, debuff, zone, projectile, stun, vol, combo. Ils vivent dans lang/templates/*.rbs.

La liste à jour des verbes est la page Catalogue. Elle est relue dans le fichier du langage à chaque génération du site.
