# Dépannage

## Test impossible

Le test s'est arrêté avant le graphe. Causes restantes : tu n'es pas en vie, le brouillon n'est pas enregistré, ou ce n'est pas un test et l'endurance bloque.

Un test ne doit plus échouer seulement parce qu'il manque un ballon, une cible ou une position. Recharge le gamemode, rouvre le studio, reteste.

## Rien n'est cliquable dans Skill rapide

La liste de type s'ouvrait derrière la fenêtre. Ferme et rouvre le studio pour prendre la nouvelle version.

## Je ne vois pas Studio, ni Tester

1. `dev 1` dans la console.
2. Ton SteamID est propriétaire.
3. Rouvre le menu des techniques.

## Le graphe a l'air bon, le test parle d'erreurs

Onglet Problèmes, ou vue Code : la ligne soulignée. Tant qu'une erreur reste, le test ne part pas.

## Les joueurs ne voient pas ma technique

Il faut Publier, puis visibilité Public.

## Deux personnes sur la même technique

Une seule écrit. L'autre est en lecture seule. Le verrou tombe après 45 secondes sans signe de vie.
