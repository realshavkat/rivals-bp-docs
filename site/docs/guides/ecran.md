# Lire l'écran

Le graphe occupe le centre. La gauche et la droite flottent par-dessus. Les onglets de techniques restent au-dessus.

## Trois vues, un seul graphe

| Vue | Rôle |
| --- | --- |
| Nodes | Les blocs et les fils. |
| Code | Le langage d'étapes. S'il y a une erreur, le graphe ne change pas. |
| Fiche | Nom, rang, style, recharge, endurance. |

## Gauche

Trois onglets : **TECHNIQUES**, **PRESETS**, **BLOCS**.

Sous Techniques : **A-Z**, **Type**, **Style**, puis **Rareté** et **Brouillon**.

Sous Blocs : **Tous**, **Flux**, **Jeu**, **Visuel**, **Valeurs**. Tu peux glisser un bloc sur le graphe.

## Droite

Dès qu'un bloc est sélectionné : **Technique** (identité, durée, style) et **Bloc** (réglages de la sélection).

## Fils

- Point blanc : l'ordre. `suite` va vers `départ`.
- Point bleu : une valeur. Le lanceur va vers le joueur.

Un double-clic sur une action assistée la déplie en blocs simples. Tu peux annuler.
